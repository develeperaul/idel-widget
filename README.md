# Виджет «Идель» для Unreal

Макет: Figma `epNsS3AUrYLq6t6aKlWDq4`, узел `247:33347`.
Это интерфейс на Vue 3 (Composition API, Single-File Components),
собранный для UMG Web Browser, не бинарный `.uasset`.
Оригинальные иконки, логотипы и фон выгружены из Figma. Nunito хранится локально,
лицензия находится в `assets/OFL.txt`. Node, npm и интернет для запуска не нужны.

## Разработка на Vue

Исходники: `src/App.vue`, `src/components/WelcomeScreen.vue`,
`SessionForm.vue`, `VirtualKeyboard.vue`, `PresentationPanel.vue`.
Общий канал команд для Unreal находится в `src/bridge.js`.
Состояние экранов управляется Vue; DOM используется только для фокуса
и позиции курсора в маске. Стили сохранены в `widget.css` и `session.css`.

Из папки `idel-widget`:

```sh
npm ci
npm run build
npm test
```

Тесты используют установленный Google Chrome. `npm run dev` запускает Vite
на `http://127.0.0.1:5173` с автообновлением Vue-компонентов (HMR).
Если порт занят, Vite выбирает следующий; точный адрес выводится в терминале.
Для прозрачного режима добавьте `?mode=unreal`. Остановка сервера: Ctrl+C.
Dev-режим использует исходники из `src`, а не ранее собранный `build/app.js`.
Для автоматической пересборки локального пакета есть `npm run watch`.
Готовая сборка по-прежнему открывается через `file://` без сервера.
Vite собирает Vue и компоненты в `build/app.js`
формата IIFE с заранее скомпилированными шаблонами; CDN и ES-модульные загрузки
при запуске отсутствуют. Сгенерированный `build/app.js` вручную не редактируйте.

Для переноса в Unreal достаточно `index.html`, двух CSS-файлов, папок `build`
и `assets`. Готовый архив содержит эти файлы и инструкцию. `node_modules`
и исходники переносить в Unreal не нужно. Адрес `index.html?mode=unreal`
и API `IdelWidget` / `IdelSession` сохранены. После `setState` Vue обновляет
DOM на следующем цикле, а `getState` сразу возвращает новое состояние.

## Сначала посмотреть

Откройте `index.html` в браузере. Фон из Figma показан только для сравнения.
Теперь первый экран предлагает начать демонстрацию. Коснитесь экрана или
нажмите кнопку, введите любой корректный российский номер (например,
`+7 (999) 123-45-67`), нажмите «Войти», выберите менеджера и снова нажмите
«Войти». После заполнения телефона список также доступен через поле менеджера.
«Гостевой вход» сразу открывает презентацию без телефона.

Это мок-сессия: номер не проверяется сервером, SMS не отправляется. Десять
менеджеров заданы в `src/components/SessionForm.vue`. Сессия хранится только в памяти страницы,
после перезагрузки снова показан стартовый экран. Номер не сохраняется и не
попадает в console-события; после входа поле очищается.
Клавиатура поддерживает RU/EN, Shift, пробел, удаление и редактирование
выделенного текста. Маска телефона `+7 (999) 999-99-99` добавляет скобки,
пробелы и дефисы автоматически; буквы игнорируются. Можно вставить номер
из буфера с префиксом +7 или 8 либо десять цифр без префикса.

В Unreal через `Execute Javascript` можно вернуть начало:
`window.IdelSession.reset();`. Событие `session.started` использует тот же
префикс `IDEL:`; params содержит `mode: manager/guest`, `mock: true` и
`manager: {id, name}` либо null. Это демонстрационный выбор, не подтверждение
личности и не авторизация для backend. Дополнительные макеты:
`247:33331`, `247:33340`, `247:33343`.

Кнопки сезонов и погоды переключают состояние; ползунок меняет часы.
Кнопка скрытия оставляет возможность снова показать интерфейс.
Остальные кнопки отправляют команды, но сами не создают галерею, фильтр квартир
или скриншот. Эти экраны отсутствуют в выбранном узле Figma.

## Проверка в Unreal Editor

Для управления камерой вне интерфейса используйте отдельные браузерные области:
инструкция и URL находятся в [PANELS.md](PANELS.md). Полноэкранная схема ниже
остаётся вариантом для первоначального просмотра, она перехватывает мышь.

1. Распакуйте готовый архив в `<ваш проект>/Content/UI/idel-widget`.
2. В `Edit > Plugins` включите `Web Browser`, перезапустите Editor.
3. Создайте `Widget Blueprint` с именем `WBP_IdelPreview`, родитель `User Widget`.
4. В Designer добавьте Canvas Panel, затем Web Browser. Назовите его `Browser`.
   Поставьте anchors на весь экран, offsets Left/Top/Right/Bottom = 0.
   Включите `Is Variable` и `Supports Transparency`.
5. В поле Initial URL укажите реальный абсолютный путь к файлу, например:
   `file:///D:/Projects/MyProject/Content/UI/idel-widget/index.html?mode=unreal`.
   Используйте прямые слеши. Пробелы в URL замените на `%20`.
   На macOS начало будет `file:///Users/.../Content/UI/idel-widget/index.html?mode=unreal`.
6. В Level Blueprint тестовой карты: `Event BeginPlay` -> `Create Widget`
   (Class = WBP_IdelPreview, Owning Player = Get Player Controller) -> `Add to Viewport`.
   Для Player Controller включите `Show Mouse Cursor` и `Set Input Mode Game and UI`.
7. Запустите Play. За прозрачным интерфейсом должна быть ваша сцена.
   Удалите `?mode=unreal` из URL, чтобы проверить полный экран с фоновой картинкой.

В DUBKI основное меню создаётся в `BP_Explorer_PC` через `Create_MasterMenu`.
Для первого опыта используйте отдельную тестовую карту: существующий
`BP_MasterMenu_Widget` содержит рабочую логику, которую нужно подключать отдельно.
Не добавляйте два полноэкранных меню одновременно при проверке ввода.

## Подключение кнопок к Blueprint

У `Browser` добавьте событие `On Console Message`. Соедините `Message` с
`Print String`: нажатия должны выводить строки с префиксом `IDEL:`.
Если события нет в вашей версии плагина, для передачи команд потребуется
расширение Web Browser на C++; визуальный просмотр не зависит от этого события.

Для быстрого опыта: `Message` -> `Contains` (`scene.home`) -> `Branch` ->
ваш существующий вызов возврата камеры домой. Для полной интеграции удаляйте
префикс `IDEL:` и разбирайте JSON, а не ищите подстроки.

Пример сообщения:

```json
{"id":"idel_2","method":"scene.setWeather","params":{"weather":"rain"}}
```

| method | params | Подключить в проекте |
| --- | --- | --- |
| ui.ready | version: 1 | Передать начальное состояние сцены |
| scene.setTime | minutes: 0..1439, hours: 0..23.9833 | Время суток в вашем sky actor |
| scene.setSeason | season: summer / autumn / winter | Сезон материалов/растительности |
| scene.setWeather | weather: clear / partlyCloudy / overcast / rain | Состояние погодной системы |
| scene.home | {} | Домашняя камера |
| scene.resetNorth | {} | Поворот камеры на север |
| scene.screenshot | {} | Существующий обработчик снимка |
| ui.info | {} | Открыть информацию |
| ui.gallery | {} | Открыть галерею |
| ui.apartments | {} | Открыть выбор квартир |
| ui.favorites | {} | Открыть избранное |
| ui.toggleVisibility | visible: boolean | Синхронизировать другие панели |

Ползунок отправляет команду при завершении изменения, чтобы не перегружать
Blueprint. При `ui.ready` вызовите `Execute Javascript` у Browser, например:

```js
window.IdelWidget.setState({minutes: 720, season: 'winter', weather: 'overcast'});
```

Начальное время 16:28 соответствует надписи в Figma; положение ползунка вычислено
по настоящему диапазону суток (в исходном макете положение не совпадает со временем).
Интерфейс рассчитан на 1920x1080 и удваивает геометрию для 4K; на узких экранах
уменьшаются внешние отступы. Значения состояния UI сами не меняют 3D-сцену.

## Ввод и сборка

Прозрачность Web Browser не означает передачу мыши в 3D через пустые пиксели.
Полноэкранный браузер может перехватывать ввод камеры. Для рабочего приложения
нужны отдельные браузерные области панелей либо обработка ввода через собственный
Slate/C++ контейнер. Этот пакет предназначен для первой визуальной проверки.

Для packaged build добавьте `UI/idel-widget` в `Project Settings > Packaging >
Additional Non-Asset Directories to Copy`. Файлы должны оставаться внешними,
доступными через file URL, а не только внутри pak. В сборке формируйте URL из
абсолютного Project Content Directory, не используйте путь разработчика D:/... .
Проверьте отдельно целевую платформу: здесь Unreal Editor и сборка не запускались.

API: https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Plugins/WebBrowserWidget/UWebBrowser
