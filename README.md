## Разработка на Vue

Исходники: `src/App.vue`, `src/components/WelcomeScreen.vue`,
`SessionForm.vue`, `VirtualKeyboard.vue`, `PresentationPanel.vue`.
Общий канал команд для Unreal находится в `src/bridge.js`.
Состояние экранов управляется Vue; DOM используется только для фокуса
и позиции курсора в маске. Стили сохранены в `widget.css` и `session.css`.

Из папки `idel-widget`:

```sh
npm ci
npm run build
npm test
```

Тесты используют установленный Google Chrome. `npm run dev` запускает Vite
на `http://127.0.0.1:5175` с автообновлением Vue-компонентов (HMR).
Порт закреплён через `strictPort`: если он занят, Vite сообщает об ошибке.
Порт 5173 не используем: на нём обнаружен сервер другого проекта, из-за которого
встроенный браузер открывал прежнюю версию с отключённой кнопкой «О проекте».
Для прозрачного режима добавьте `?mode=unreal`. Остановка сервера: Ctrl+C.
Dev-режим использует исходники из `src`, а не ранее собранный `build/app.js`.
Для автоматической пересборки локального пакета есть `npm run watch`.
Готовая сборка по-прежнему открывается через `file://` без сервера.
Vite собирает Vue и компоненты в `build/app.js`
формата IIFE с заранее скомпилированными шаблонами; CDN и ES-модульные загрузки
при запуске отсутствуют. Сгенерированный `build/app.js` вручную не редактируйте.

Для переноса в Unreal нужны `index.html`, файлы `widget.css`, `session.css`,
`location.css`, `project.css`, `apartments.css`, `saved.css`, папки `build`
и `assets`. Актуальный архив можно пересоздать после сборки командой
`python3 scripts/package_unreal.py ../idel-widget-2026-10-13-screenshot-flight.zip`; скрипт
проверит состав и целостность ZIP. `node_modules`
и исходники переносить в Unreal не нужно. Адрес `index.html?mode=unreal`
и API `IdelWidget` / `IdelSession` сохранены. После `setState` Vue обновляет
DOM на следующем цикле, а `getState` сразу возвращает новое состояние.

## Сначала посмотреть

Откройте `index.html` в браузере. Фон из Figma показан только для сравнения.
Теперь первый экран предлагает начать демонстрацию. Коснитесь экрана или
нажмите кнопку, введите любой корректный российский номер (например,
`+7 (999) 123-45-67`), нажмите «Войти», выберите менеджера и снова нажмите
«Войти». После заполнения телефона список также доступен через поле менеджера.
«Гостевой вход» сразу открывает презентацию без телефона.

В текущем `index.html` включён реальный вход через `http://idel.yes-project.ru/api`:
`realSession:true`, `allowHttpSession:true`. Первый шаг проверяет телефон.
Существующий клиент входит со своим менеджером. Для нового клиента открывается
регистрация: ФИО, менеджер из API и согласие. ФИО вводится одной строкой: фамилия,
имя, затем необязательное отчество. Экранная клавиатура редактирует выбранное поле.

`POST /api/session` получает `{mode:'manager',phone}`. Неизвестный телефон
возвращает `registrationRequired:true`; затем `POST /api/session/register`
сохраняет клиента, выбранного менеджера и связанную сессию. Гость передаёт только
`{mode:'guest'}`. Ссылка согласия пока пустая; позже задайте `IdelConfig.consentUrl`.

HTTP разрешён явно в настройках интерфейса и сервера. Сервер принимает Origin
`http://idel.yes-project.ru`, `http://127.0.0.1:5175` и `http://localhost:5175`.
Для запуска используйте `npm run dev -- --port 5175` либо настройте Origin под
фактический адрес. По отдельному разрешению пользователя API теперь также
принимает точный Origin `null` для загрузки локального `file://` виджета.
Для автономного превью задайте `window.IdelConfig.realSession=false` до `build/app.js`.

Токен остаётся только в памяти Browser и используется в `/api/favorites`.
`session.started` и `IdelSession.getState()` содержат `{mode,mock,manager,client:{id}}`
без телефона, ФИО клиента и токена. `IdelSession.reset()` возвращает начало и
отменяет незавершённые запросы. Между отдельными Web Browser токен автоматически
не передаётся; серверное избранное работает в том же полном Browser.

Проверены сборка, 13 проверок логики, Chrome на четырёх размерах и API-сценарии.
Живой HTTP API проверен с временным клиентом и реальными привязками Bitrix;
тот же полный вход прошёл из локального `file://` в Chrome.
В Play и packaged build новый вход ещё не проверен.
Дополнительные макеты:
`247:33331`, `247:33340`, `247:33343`.

Кнопки сезонов и погоды переключают состояние; ползунок меняет часы.
Кнопка скрытия оставляет возможность снова показать интерфейс.
Кнопка «О проекте» открывает экран 05 «Локация»; повторное нажатие или «Домой»
возвращает экран 04. Галерея и фильтры квартир открываются локально в полном
интерфейсе; снимок запрашивается у Unreal по `scene.screenshot`.

## Проверка в Unreal Editor

Для управления камерой вне интерфейса используйте отдельные браузерные области:
инструкция и URL находятся в [PANELS.md](PANELS.md). Полноэкранная схема ниже
остаётся вариантом для первоначального просмотра, она перехватывает мышь.
Шаги 1–7 ниже описывают **чистый проект**. В текущем IDEL Web Browser уже включён,
виджет создан как `/Game/wbp-idelpreview`, а `Create Widget → Add to Viewport`
уже собран в `BP_CameraPlayerController`, но его Save пока не прошёл.
Актуальные путь `Content/idel-widget`, URL и порядок продолжения —
в [UNREAL_RESTORE_IDEL.md](../UNREAL_RESTORE_IDEL.md).

1. Распакуйте готовый архив в `<ваш проект>/Content/UI/idel-widget`.
2. В `Edit > Plugins` включите `Web Browser`, перезапустите Editor.
3. Создайте `Widget Blueprint` с именем `WBP_IdelPreview`, родитель `User Widget`.
4. В Designer добавьте Canvas Panel, затем Web Browser. Назовите его `Browser`.
   Поставьте anchors на весь экран, offsets Left/Top/Right/Bottom = 0.
   Включите `Is Variable` и `Supports Transparency`.
5. В поле Initial URL укажите реальный абсолютный путь к файлу, например:
   `file:///D:/Projects/MyProject/Content/UI/idel-widget/index.html?mode=unreal`.
   Используйте прямые слеши. Пробелы в URL замените на `%20`.
   На macOS начало будет `file:///Users/.../Content/UI/idel-widget/index.html?mode=unreal`.
6. В Level Blueprint тестовой карты: `Event BeginPlay` -> `Create Widget`
   (Class = WBP_IdelPreview, Owning Player = Get Player Controller) -> `Add to Viewport`.
   Для Player Controller включите `Show Mouse Cursor` и `Set Input Mode Game and UI`.
7. Запустите Play. За прозрачным интерфейсом должна быть ваша сцена.
   Удалите `?mode=unreal` из URL, чтобы проверить полный экран с фоновой картинкой.

Для первого опыта используйте отдельную тестовую карту и не добавляйте два
полноэкранных меню одновременно при проверке ввода.

## Подключение кнопок к Blueprint

У `Browser` добавьте событие `On Console Message`. Соедините `Message` с
`Print String`: нажатия должны выводить строки с префиксом `IDEL:`.
Если события нет в вашей версии плагина, для передачи команд потребуется
расширение Web Browser на C++; визуальный просмотр не зависит от этого события.

Для быстрого опыта: `Message` -> `Contains` (`scene.home`) -> `Branch` ->
ваш существующий вызов возврата камеры домой. Для полной интеграции удаляйте
префикс `IDEL:` и разбирайте JSON, а не ищите подстроки.

Пример сообщения:

```json
{"id":"idel_2","method":"scene.setWeather","params":{"weather":"rain"}}
```

| method | params | Подключить в проекте |
| --- | --- | --- |
| ui.ready | version: 1 | Передать начальное состояние сцены |
| scene.setTime | minutes: 0..1439, hours: 0..23.9833 | Время суток в вашем sky actor |
| scene.setSeason | season: summer / autumn / winter | Сезон материалов/растительности |
| scene.setWeather | weather: clear / partlyCloudy / overcast / rain | Состояние погодной системы |
| scene.home | {} | Домашняя камера |
| scene.resetNorth | {} | Поворот камеры на север |
| scene.screenshot | captureId, propertyId | Сделать снимок сцены и вернуть `IdelApartments.setScreenshot` |
| ui.info | {} | Открыть информацию |
| scene.apartments.floor | revision, sectionId, floor, items | Камера и подсветка выбранного этажа |
| ui.apartments | mode, filters | Открыть выбор квартир |
| session.ended | savedLocally, archiveId | Свернуть панели после выхода из сессии |
| ui.toggleVisibility | visible: boolean | Синхронизировать другие панели |

Галерея и «Сохранённое» открываются локально в полном Vue-экране. Для Unreal
добавлены отдельные `?mode=unreal&panel=gallery|saved`; изолированный toolbar
отправляет `ui.gallery`/`ui.favorites`, чтобы показать нужный Browser. У каждого
Browser своё состояние: перед показом сохранённого перенесите
`IdelApartments.getMaterials()` из владельца в BrowserSaved через
`IdelApartments.setMaterials(...)`. Изображения галереи — ассеты макета.
После подтверждённого `setScreenshot` миниатюра снимка летит от кнопки камеры
к сердцу без числового индикатора. Снимок доступен в «Сохранённом» до конца
сессии. При выходе только избранные объекты можно сохранить в локальный
IndexedDB: `IdelSession.listArchives/getArchive/deleteArchive`. Новые архивы
не содержат снимков; удаление самих PNG по `session.ended` нужно подключить
в Unreal. Локальный архив не даёт доступа клиенту с другого устройства. Почта, Telegram, MAX, QR и PDF
ждут API-04 и настройки провайдеров; кнопка «Отправить» пока отключена.

Ползунок отправляет `scene.setTime` при каждом изменении значения (`input`),
включая перемещение с зажатой кнопкой мыши и управление с клавиатуры. При `ui.ready` вызовите `Execute Javascript` у Browser, например:

```js
window.IdelWidget.setState({minutes: 720, season: 'winter', weather: 'overcast'});
```

Начальное время 16:28 соответствует надписи в Figma; положение ползунка вычислено
по настоящему диапазону суток (в исходном макете положение не совпадает со временем).
Интерфейс рассчитан на 1920x1080 и удваивает геометрию для 4K; на узких экранах
уменьшаются внешние отступы. Значения состояния UI сами не меняют 3D-сцену.

## Ввод и сборка

Прозрачность Web Browser не означает передачу мыши в 3D через пустые пиксели.
Полноэкранный браузер может перехватывать ввод камеры. Для рабочего приложения
нужны отдельные браузерные области панелей либо обработка ввода через собственный
Slate/C++ контейнер. Этот пакет предназначен для первой визуальной проверки.

Для packaged build добавьте `UI/idel-widget` в `Project Settings > Packaging >
Additional Non-Asset Directories to Copy`. Файлы должны оставаться внешними,
доступными через file URL, а не только внутри pak. В сборке формируйте URL из
абсолютного Project Content Directory, не используйте путь разработчика D:/... .
Проверьте отдельно целевую платформу: здесь Unreal Editor и сборка не запускались.

API: https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Plugins/WebBrowserWidget/UWebBrowser

### Выбор квартир — экраны 11–13

Открыть локально: `http://127.0.0.1:5175/?view=apartments` либо кнопкой
«Выбор квартир». Старт: только «Фасад», фильтры пустые. Каталог и карточки
загружаются из существующего API. Для проверки выбора без Unreal переключитесь
на «Списком» и нажмите квартиру; «Подробнее» откроет полную карточку.
Фасад — исходный фон Figma только для предпросмотра; в mode=unreal фона нет.
Подсветку и снимки создаёт Unreal. Демонстрационные данные в production не подмешиваются.
«Вид из окна» теперь открывает самостоятельный экран поверх 3D: внизу переключатель
видов 1–3, сверху карточка квартиры и «Назад», справа управление взглядом.
Команды `scene.apartment.window`, `.pan`, `.close` и `scene.resetNorth` описаны
в `EVENTS.md`. Панорамные изображения Figma видны только в браузерном превью;
в режиме Unreal фон прозрачен, реальные ракурсы и метки создаёт сцена.

Галерея по умолчанию показывает 25 изображений макета. Для будущего API-05
задайте до `build/app.js` `IdelConfig.galleryApi=true` и числовой
`IdelConfig.galleryComplexId`. Тогда Vue запрашивает
`GET /api/presentation/gallery?residentialComplex=<ID>`, сортирует ответ по
`sort` и показывает ошибку/повтор или пустой список, если данных нет. Этот
режим проверен тестом с перехваченным HTTPS-ответом; на backend маршрут пока
не опубликован. Нужны доступные Web Browser URL изображений и разрешённый CORS.

Vite проксирует `/api` и `/upload` на `http://idel.yes-project.ru`.
Параметр `residentialComplex` удалён из запросов: у API один проект, а его
передача возвращает пустой каталог. ID секций берутся из метаданных.
Для другой среды задайте перед подключением app.js:

```html
<script>
window.IdelConfig = {
  apiBaseUrl: 'https://YOUR_API_HOST/api'
};
</script>
```

При обычной HTTP-загрузке без конфигурации используется `/api`, при file:// —
публичный HTTP-каталог. Для file:// требуется разрешение CORS origin null на
сервере; текущая конфигурация backend его по умолчанию не разрешает. Предпочтительна
подача страницы с разрешённого HTTP(S) origin. Избранное требует настоящего
session token и разрешённый транспорт; мок-вход не авторизует эти запросы. Токен передаётся через
IdelApartments.setSessionToken, не через URL. Полный контракт — EVENTS.md §9,
порядок подключения Unreal и ограничения отдельных панелей — PANELS.md.

Проверка новых сценариев: `node apartments.test.cjs` после `npm run build`.
Тест использует явно перехваченные ответы API, не меняет реальный каталог.
