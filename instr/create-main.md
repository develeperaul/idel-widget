Понял вас! Вы прислали инструкцию по подключению веб-виджета в Unreal Engine.
Поскольку вы остановились на моменте вывода виджета на экран, давайте сделаем этот финальный шаг, чтобы всё заработало при нажатии кнопки Play.
## Выводим виджет на экран через Level Blueprint

   1. В верхнем меню Unreal Engine нажмите кнопку Blueprints и выберите Open Level Blueprint.
   2. Нажмите правой кнопкой мыши (ПКМ) на пустом месте графика и найдите событие Event Begin Play.
   3. Вытяните нить (wire) из узла Event Begin Play и в поиске введите Create Widget. Выберите этот узел.
   4. В самом узле Create Widget в поле Class выберите из выпадающего списка ваш созданный виджет: WBP_IdelPreview.
   5. Теперь вытяните нить из выхода Return Value (синий кружок на узле Create Widget) и в поиске найдите узел Add to Viewport. Соедините их.
   6. В левом верхнем углу окна Blueprint нажмите Compile, а затем Save.

------------------------------
## Проверка работы
Запустите игру, нажав кнопку Play в редакторе. Если вы правильно указали путь в поле Initial URL на 5-м шаге, ваш HTML-виджет должен успешно отобразиться поверх игрового экрана.
Если что-то пошло не так, дайте знать:

* Появился ли черный или белый экран вместо виджета?
* Видите ли вы какие-то ошибки в логе (Output Log)?
* Нужно ли помочь с настройкой мыши, чтобы кликать по элементам виджета в игре?
